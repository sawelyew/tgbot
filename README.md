# Telegram Order Manager

Бот для автоматизации приема заказов. Позволяет клиентам оформить заявку через форму (FSM), а администраторам — управлять ботом динамически через Telegram.

## Функционал

**Для пользователей:**
- **Интерактивное меню:** Быстрый доступ к прайсу, контактам и FAQ.
- **Умный сбор заявок:** Пошаговый опрос для формирования заказа.
- **Уведомления:** Заявка сразу перелетает в рабочую группу администраторов.

**Для администраторов:**
- **Динамическое управление:** Изменение текстов, цен и FAQ через интерфейс бота.
- **Работа с медиа:** Возможность менять картинку в главном меню через админ-панель.

## Команды бота

| Команда  | Описание |
|:---------| :--- |
| `/start` | Запуск бота и главное меню |
| `/panel` | Панель управления контентом |

## Как запустить

### 1. Подготовка окружения
Создайте файл `.env` в корневой папке проекта и заполните его:
```
API_TOKEN=token
CHAT_ID=id
ADMIN_IDS=id
DB_USER=user
DB_PASSWORD=password
DB_NAME=name
DB_HOST=shop_db # Для Docker - shop_db, для локального — localhost
DB_PORT=5432
```
### 2. Запуск через Docker
``` 
docker-compose up --build
```
### 3. Локальный запуск
#### 1. Активируйте виртуальное окружение
``` 
python -m venv venv
Windows: venv\Scripts\activate | Mac/Linux: source venv/bin/activate
```
#### 2. Установите зависимости
``` 
pip install -r requirements.txt
```
#### 3. Запуск бота
``` 
python main.py
```
